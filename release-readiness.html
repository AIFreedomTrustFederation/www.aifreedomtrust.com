Guided release pathway

What is ready?

Only changes with exact-head CI, required reviews, mergeability, protection checks and dependency closure can be called verified. No PR is promoted by title alone.

What is blocked?

Missing head-SHA evidence, unresolved reviews, security boundaries, branch rules or upstream stacked PRs remain explicit blockers.

What is next?

Inspect the linked PR, confirm its current head SHA, checks and protection rules, resolve upstream dependencies, then request review where required.
