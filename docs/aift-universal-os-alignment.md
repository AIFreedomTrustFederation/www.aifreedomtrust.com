## Role and separation

**Public portal:** Continue delivering the published Tree of Emergence, seven Movements and Articles, source-backed exploration, imagery, accessible mobile/desktop HTML and real destinations. Do not replace its philosophical voice with repository engineering language.

**Proposed OS desktop:** A related *separate application surface* may evolve the Living Universe look-and-feel into a windowed workspace, launcher, files, settings, notifications and AI assistant. OS and VPS/Runtime services own data and execution; the public site cannot silently acquire privileged APIs.

**Proposed pre-boot visual identity:** Share only assets/design tokens with a native UEFI or model-supported boot app. A preboot interface cannot be assumed to run the public website's JavaScript, CSS, browser or server.

## Tree and cinematic invariants

Roots are repositories and source/provenance; trunk verified federation integration; branches real systems; leaves documented knowledge; flowers evidenced emerging work; fruits real visitor-facing outcomes with working links. A repository is **never a fruit**. Do not fabricate progress, operational status, XP, evidence or a verified device.

## Incremental desktop acceptance

1. Prove current mobile and Chromium public journeys at 360/390/768/1280 pixels with navigation, reversible breadcrumbs, keyboard, touch and correct pointer hit regions.
2. Define a separate OS desktop prototype behind honest feature flags and testable API contracts; no public illusion of live filesystem or application execution.
3. Launch one real app using Forge manifest and host/hosted session adapter with explicit permissions.
4. Verify real file/status data, failures and graceful offline behavior; capture evidence for native and hosted modes **separately**.
5. Evaluate pre-boot visual assets only against a working UEFI test app and QEMU/OVMF evidence owned by AIFT-OS.
