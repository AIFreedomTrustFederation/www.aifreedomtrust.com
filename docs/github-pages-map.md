## Root landing page requirement

To use:

```text
https://aifreedomtrustfederation.github.io/
```

create a public repository named exactly:

```text
AIFreedomTrustFederation/aifreedomtrustfederation.github.io
```

That repository should contain a static `index.html` landing page linking all public project pages above.

Until that root repository exists, `www.aifreedomtrust.com` remains the public landing page and project map.
