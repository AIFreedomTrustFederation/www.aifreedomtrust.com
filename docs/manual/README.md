# www.aifreedomtrust.com UNIX Manual Manual

This directory contains the UNIX-style manual source for this repository.

Manual source belongs to this repo. PDF and publication builds belong to BookSmith.

**Source coverage and publication status.** The [manual manifest](../../.aift/manual.json) reserves `man0` through `man9`, but authored manual pages currently exist only under [`source/man0/`](source/man0/) and [`source/man7/`](source/man7/); the other categories are index entries, not completed sections. The manifest's `manualSource: ready` describes the available source contract, while `pdfBuild` and `webPublish` remain `planned`. This repository does not establish a built, approved, or published manual PDF.
