03 · Transparent maturity

Clarity before claims

Shared labels help readers distinguish working products, foundational systems, research and archival work.

Active productInfrastructureFederation coreResearchIncubatingLegacyFork
How should repository status be interpreted?

Active product means actively maintained and public-facing. Infrastructure indicates platform or deployment tooling. Federation core covers shared doctrine, templates and identity. Research denotes experimental models, datasets or protocols. Incubating is not yet a primary public surface; Legacy is retained for reference; Fork identifies external code.

What are the immediate documentation priorities?

Standardize repository READMEs and status labels, add issue and pull-request templates to active repositories, preserve a canonical public portal, and explicitly review incubating or forked repositories before presenting them as original active products.

Where is the canonical source?

Read the organization-map.md document. This page is a visual interpretation of that source; future architecture changes should keep both synchronized.
